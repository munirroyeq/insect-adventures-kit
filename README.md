# Insect Adventures Kit

A small Claude plugin for making kid-friendly insect video scripts.

## What it does

- `insect-script` skill: writes a 2 to 3 minute script with a hook, 3 science facts, a character moment, a 3-question quiz, and a fact-check list.

## Use it

After installing the plugin, ask Claude:
"Write an insect script about the ladybug."
